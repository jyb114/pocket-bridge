About this connection

Keep the official desktop app open and signed in. Leave the computer free while using phone mode.

Only recent loaded messages are shown. Use the desktop for files, calls, approvals and task controls. Local task execution remains unverified.

After connecting, drafts can be recovered by reloading this tab and reconnecting to the same Dot. Closing the tab may lose them. Recovery never sends a message.

Privacy and delivery details

Connecting and refreshing briefly use the computer and its clipboard. An existing desktop draft is preserved.

Drafts and unresolved request text are saved in this tab's session storage in plain text, separately for this phone connection and verified Dot. Browser storage is not encrypted at rest.

When sending is available, a receipt confirms only that the exact new message appeared in desktop Dot. Server acknowledgement and task execution are unverified. An uncertain send is never retried automatically.
