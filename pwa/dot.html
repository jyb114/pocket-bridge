About this connection

Your dot runs through the official desktop app. Keep it open and signed in.

Only messages currently loaded in the desktop app can be shown. Use the desktop for attachments, calls, approvals and task controls.

A connected computer does not prove that Dot can run local tasks. Local execution and task status remain unverified.

Connecting and refreshing briefly use the computer and its clipboard. An existing desktop draft is preserved. Do not use the computer at the same time.

When text sending is available, a receipt confirms only that the exact new message appeared in the desktop Dot conversation. An uncertain send is never retried automatically.
